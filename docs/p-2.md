## 1. Deep Codebase Audit & Current State Analysis

Following an line-by-line inspection of all subdirectories and source files across `apps/backend/src`, `apps/frontend/src`, `packages/schemas`, and `packages/config`, the current state of NotifyIQ is documented below:

### 1.1 Meta & WABA Integration Module (`apps/backend/src/meta`)
- **Current File**: `meta.service.ts`, `meta.controller.ts`
- **What is Implemented**: Basic `connectWaba` endpoint (`POST /api/waba/connect`) that receives `accessToken`, `phoneNumberId`, and `businessAccountId`, calls `https://graph.facebook.com/v20.0/oauth/access_token` to exchange tokens, subscribes webhooks, encrypts credentials via AES-256-GCM, and updates `workspace.waba`.
- **Missing Gaps for Phase 2**:
  - Meta Embedded Signup OAuth popup flow (`POST /api/waba/embedded-signup/callback` to exchange Meta authorization `code` directly from Facebook popup).
  - WABA Business Profile API (`GET /api/waba/profile` & `POST /api/waba/profile`) to query and update business description, vertical address, support email, website, and profile logo via Meta Graph API v20.0.
  - WhatsApp Message Template Engine (`GET /api/waba/templates`, `POST /api/waba/templates`, `DELETE /api/waba/templates/:name`) to build and submit outbound message templates for 24+ hour window communications.
  - WABA Profile Management UI (`WabaProfilePage.tsx`) and Template Builder UI (`TemplateBuilderPage.tsx`).

### 1.2 AI & RAG Infrastructure Module (`apps/backend/src/ai`)
- **Current Files**: `rag.service.ts`, `sentiment.service.ts`, `suggestions.service.ts`, `whisper.service.ts`, `ai.controller.ts`
- **What is Implemented**:
  - `rag.service.ts`: Raw text string ingestion with hardcoded OpenAI `text-embedding-3-small` API calls and Claude `claude-3-haiku-20240307` API calls, with fallback to basic string regex matching.
  - `sentiment.service.ts`: Calls Anthropic Claude API to classify text into `positive`, `neutral`, `negative`, `urgent`.
  - `suggestions.service.ts`: Calls Anthropic Claude API to generate 3 reply options.
- **Missing Gaps for Phase 2**:
  - `GeminiService` using `@google/genai` (or Gemini REST API with `GEMINI_API_KEY`) is missing.
  - Refactoring `SentimentService`, `SuggestionsService`, and `RagService` to use **Google Gemini AI Suite** (`gemini-3.5-flash-lite` for completions/chat and `gemini-embedding-001` [768-dim] for embeddings) is required.
  - Multi-format file parsing (`DocumentParserService`) for `.docx` (mammoth), `.pdf` (pdf-parse), `.csv` (csv-parse), `.yaml` (js-yaml), `.json`, and `.txt` is missing.
  - Document chunking (`ChunkingService`) using recursive character text splitting (500 tokens / 50 overlap) is missing.
  - Exact Cosine Similarity vector matching fallback in Node.js (when MongoDB Atlas Vector Search index is offline) is missing.
  - Multipart file upload API endpoint (`POST /api/kb/upload`) and Knowledge Base Management UI (`KnowledgeBasePage.tsx`) are missing.

### 1.3 Webhook Engine & Queue Workers (`apps/backend/src/queues/workers`)
- **Current Files**: `webhook.worker.ts`, `campaign.worker.ts`, `sentiment.worker.ts`
- **What is Implemented**:
  - `webhook.worker.ts` receives raw Meta webhook events, resolves workspace by `waba.phoneNumberId`, creates/retrieves contact, creates conversation, saves message record, emits Socket.io event to room `workspace:{id}`, and delegates jobs to `sentiment-analysis` and `audio-processor`.
- **Missing Gaps for Phase 2**:
  - Auto-reply evaluation is NOT yet invoked in `webhook.worker.ts`.
  - In Phase 2, `webhook.worker.ts` must check workspace `autoReplySettings`, verify operating hours, query Gemini RAG Knowledge Base, check confidence score, and automatically dispatch auto-replies or trigger live agent handoffs.

### 1.4 Database Schemas (`apps/backend/src/database/schemas`)
- **Current Schemas**: `workspace.schema.ts`, `user.schema.ts`, `contact.schema.ts`, `conversation.schema.ts`, `message.schema.ts`, `knowledge.schema.ts`, `audit-log.schema.ts`, `api-key.schema.ts`, `flow.schema.ts`
- **Missing Gaps for Phase 2**:
  - `workspace.schema.ts`: Needs `autoReplySettings` subdocument (`enabled`, `systemPrompt`, `confidenceThreshold`, `fallbackToHuman`, `outOfHoursOnly`, `operatingHours`, `outOfHoursMessage`).
  - `knowledge.schema.ts`: Needs `docId`, `fileName`, `fileType`, `chunkIndex`, `content`, and 768-dim `embedding` array.

### 1.5 Frontend Dashboard (`apps/frontend/src/pages`)
- **Current Pages**: `LoginPage.tsx`, `RegisterPage.tsx`, `InboxPage.tsx`, `ContactsPage.tsx`, `CampaignsPage.tsx`, `FlowBuilderPage.tsx`, `BillingPage.tsx`, `SettingsPage.tsx`
- **What is Implemented**: Auth pages, Inbox thread viewer, Contacts directory with DPDP actions, Campaign launching, Flow Builder layout, Billing status, and Settings with local state.
- **Missing Gaps for Phase 2**:
  - `WabaProfilePage.tsx`: Meta Embedded Signup button and WABA Profile management (bio, email, address, logo).
  - `TemplateBuilderPage.tsx`: Interactive Message Template builder for 24+ hour outbound communications.
  - `KnowledgeBasePage.tsx`: Document upload dropzone (.docx, .pdf, .yaml, .json, .csv, .txt), chunk list, and vector status.
  - Auto-Reply Configuration tab in `SettingsPage.tsx` connected to real workspace endpoints.

### 3.2 Extended Mongoose Schemas

#### 1. Extended `WorkspaceSchema` (`workspace.schema.ts`)
```typescript
@Prop({
  type: {
    enabled: { type: Boolean, default: false },
    systemPrompt: {
      type: String,
      default: 'You are NotifyIQ AI assistant. Answer customer questions concisely and politely using only the provided knowledge base context.',
    },
    confidenceThreshold: { type: Number, default: 0.70 }, // Minimum similarity score (0.0 - 1.0)
    fallbackToHuman: { type: Boolean, default: true },
    outOfHoursOnly: { type: Boolean, default: false },
    operatingHours: {
      enabled: { type: Boolean, default: false },
      timezone: { type: String, default: 'Asia/Kolkata' },
      workDays: { type: [Number], default: [1, 2, 3, 4, 5] }, // Mon - Fri
      startTime: { type: String, default: '09:00' },
      endTime: { type: String, default: '18:00' },
    },
    outOfHoursMessage: {
      type: String,
      default: 'Thank you for reaching out! Our team is currently offline. We will respond during business hours.',
    },
  },
  default: {},
})
autoReplySettings: {
  enabled: boolean;
  systemPrompt: string;
  confidenceThreshold: number;
  fallbackToHuman: boolean;
  outOfHoursOnly: boolean;
  operatingHours: {
    enabled: boolean;
    timezone: string;
    workDays: number[];
    startTime: string;
    endTime: string;
  };
  outOfHoursMessage: string;
};
```

#### 2. Updated `KnowledgeSchema` (`knowledge.schema.ts`)
```typescript
@Schema({ timestamps: true })
export class Knowledge {
  @Prop({ required: true, type: MongooseSchema.Types.ObjectId, ref: 'Workspace', index: true })
  workspaceId: MongooseSchema.Types.ObjectId | string;

  @Prop({ required: true })
  docId: string; // Grouping identifier for chunks of the same file

  @Prop({ required: true })
  title: string;

  @Prop({ required: true, enum: ['pdf', 'docx', 'yaml', 'json', 'csv', 'txt'] })
  fileType: string;

  @Prop({ required: true, default: 0 })
  chunkIndex: number;

  @Prop({ required: true })
  content: string;

  @Prop({ type: [Number], required: true }) // 768 dimensions for Gemini gemini-embedding-001
  embedding: number[];
}
```
